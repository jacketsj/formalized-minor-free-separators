# Formalized minor-free separators

A formalization of the main theorem (with a strenghtened constant) in
*K_h-Minor-Free Graphs Have Balanced Separators of Size O(h√n)*
by Jonathan Conroy, Hung Le, and Jack Spalding-Jamieson.
Specifically, this repository contains a formalization of the following statement:
> Every finite simple graph with `n` vertices and no `K_h` minor has a subset `S` of at most `3.2 h √n` vertices such that every connected component of `G - S` has at most `n/2` vertices.

The main statement can be found in [`statement.lean`](statement.lean).
The key definitions that the statement uses can be found in [`definitions.lean`](definitions.lean).
The proof of the statement can be found in [`proof/`](proof).

All code in this repository (except for this README) was generated by GPT-6 Astra and Claude Opus 5.5. The authors have checked that the definitions and the statement match the english-language description above, and that the code compiles.
The authors have _not_ manually checked the proof directory to ensure it lines up with the methodology presented in the paper.
